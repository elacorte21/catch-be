# Backend Developer Test: CRUD API with Python

[Backend challenge](https://github.com/catch-design/be-dev-test/)

### Tech Stack
- FastAPI
- SQLite
- SQLAlchemy

### Features
- PyCharm .http testing
- Pagination
- Full CRUD endpoints

---

### Steps 
1. Run project in Pycharm
2. Install dependencies `pip install -r requirements.txt`
3. Import CSV to catch_db.db (generated file) in Customers table
4. Open `test_main.http` file and run each test endpoints
